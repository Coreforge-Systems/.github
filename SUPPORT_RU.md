# Поддержка

По вопросам конкретного продукта используйте трекер issues или канал поддержки соответствующего репозитория.

Прежде чем создавать issue, ознакомьтесь с README репозитория, существующими issues, документацией проекта и поддерживаемой версией.

Используйте предусмотренные формы для сообщений об ошибках, запросов новых возможностей и архитектурных предложений.

Не сообщайте об уязвимостях через публичные issues; следуйте [политике безопасности](SECURITY_RU.md).
