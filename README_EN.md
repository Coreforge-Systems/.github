# Coreforge Systems · .github

Organization-wide GitHub configuration and community health files for **Coreforge Systems**.

## Purpose

Shared defaults for Coreforge Systems repositories:

- public organization profile;
- contribution guidelines;
- pull request conventions;
- issue forms;
- security reporting guidance;
- support guidance.

Project-specific repositories may override these defaults when stricter rules are required.
