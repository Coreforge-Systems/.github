# Support

For product-specific questions, use the issue tracker or support channel of the relevant repository.

Before opening an issue, check the repository README, existing issues, project documentation, and supported version.

Use the provided forms for bug reports, feature requests, and architecture proposals.

Do not use public issues for vulnerabilities; follow [the security policy](SECURITY_EN.md).
